# ClubOS v28

- Members (including pending applicants) can complete/edit full personal, contact, address, emergency, medical/accessibility details and photo.
- Full-access admins can edit the same member information from Member Register.
- Admin photo upload uses the same member photo record/storage as the Member Portal.
- Admin member edits continue to write to audit logs.
- Pending members see a clear prompt to complete their profile while awaiting approval.
- No new SQL is required if the existing member self-service/storage migrations are already installed.
