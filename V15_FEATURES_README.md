# ClubOS v15 — Member Register Filters

The Member Register now includes operational filters for:

- Membership Type (including Life Member and any organisation-defined type)
- Member Status
- Team
- Age Group (Adult 18+, Junior under 18, DOB not recorded)
- Voting Eligibility
- Fee Status (current, overdue, no paid-until date)
- Search by name, preferred name, member number, email or phone

Filters can be combined. The registry count and pagination reflect the filtered result set, and a Clear Filters action restores the full register.

No database migration is required for v15 because the filters use existing ClubOS membership, team, member and fee fields.
