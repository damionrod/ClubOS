# ClubOS v38

Member Portal layout-only simplification:
- Five core navigation items on desktop and mobile: Home, Events, Voting, News, More.
- Membership, Payments, Shop, Donate, Profile and Documents remain available through Home/More.
- Home screen simplified to attention alerts, compact membership card, four quick actions and a short team summary.
- New News/Updates show an unread badge in navigation and an alert on Home.
- Opening News & Updates marks current updates as read for that member/browser.
- Voting badge remains unchanged.
- No database migration required.
