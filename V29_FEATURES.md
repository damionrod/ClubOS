# ClubOS v29

- Clicking an event title opens a full Event Detail view.
- Admins can see every sold/issued ticket individually.
- Ticket detail includes ticket code, ticket type, attendee, purchaser, payment status, order total, purchase time and check-in status.
- Event Detail includes ticket/order/check-in/revenue summary cards.
- Admins can export the ticket-by-ticket report or edit the event directly.
- No new SQL is required.
